## 1. Сводка исправлений и Before / After по экранам

### 1.1 Экран «Настройки» (SettingsScreen)
- **Было:**
  - Огромный пустотный интервал (~100–150 dp) между subtitle и первой карточкой (`PocketTwoRowsTopAppBar`).
  - Статусный бейдж `Активен` переносился на три строки (`АКТИВ\nЕН`).
  - Карточки Claude Code и Codex создавали впечатление полностью рабочего ACP-клиента.
  - Отсутствовал доступ к экрану «Центр рантайма» (`RuntimeCenterRoute`).
  - Онбординг первого запуска не вызывался.
- **Стало:**
  - `PocketTwoRowsTopAppBar` оптимизирован: subtitle ограничен `maxLines = 1`, `overflow = Ellipsis` и `weight(1f, fill = false)`, вертикальный отступ приведен к 24 dp.
  - `PocketStatusPill` получил `maxLines = 1` и `softWrap = false`, перенос слов исключен на уровне базового токена.
  - Claude Code и Codex честно помечены статусом «В разработке (Этап 3)», кнопки запуска отключены.
  - На карточке локального рантайма появилась кнопка «Центр», открывающая `RuntimeCenterRoute`.
  - Подключен `OnboardingDialog` при первом запуске приложения.

### 1.3 Экран «Проекты» (ProjectsScreen)

## 2. Сетка и отступы (4dp Grid System)

- **Базовый модуль:** 4 dp.
- **Горизонтальный padding экрана:** 20 dp (`PocketSpacing.screenHorizontal`).
- **Внутренний padding карточек:** 16 dp (`PocketSpacing.cardPadding`).
- **Вертикальные интервалы:**
  - Межстрочный интервал заголовка и подписи: 6–8 dp.
  - До первого контентного блока: 20–24 dp.
  - Между строками списков: 8–10 dp.
  - Между секциями: 24–32 dp.
- **Минимальный размер интерактивных зон:** 48 × 48 dp.

---

## 3. Цветовая система и токены (Material 3 Expressive)

- **Primary:** главное действие (кнопки отправки, активные маркеры).
- **SecondaryContainer / OnSecondaryContainer:** навигационные индикаторы и выбранные фильтры.
- **SurfaceContainer / SurfaceContainerLow:** подложки карточек без постоянных контрастных обводок.
- **SurfaceContainerHigh:** модальные bottom sheets и диалоги.
- **Status Colors:**
  - Зеленый (`Ready` / `Running`) сопровождается текстовым описанием и иконкой.
  - Красный (`Error`) используется только для критических сбоев.
